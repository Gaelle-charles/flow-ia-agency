# Audit du positionnement et correspondance éditoriale

Date : 7 septembre 2026

## Périmètre analysé

- configuration et contenus centraux de marque ;
- homepage et routes Réalisations, Cas d’usage, Approche, À propos, Journal et Contact ;
- anciennes routes CRM, automatisation et agentique ;
- offres, méthode, équipe, preuves et formulaire ;
- document d’identité et brand kit source.

## Compatible et préservé

| Élément existant | Décision |
| --- | --- |
| Point de départ dans le travail réel | Conservé comme fondement du problème opérationnel. |
| Connexion des données, outils et équipes | Conservée et intégrée à la promesse Intelligent Operations. |
| Contrôle humain, traçabilité et moindre privilège | Conservés comme garde-fous de la couche Intelligence. |
| Réalisation QBR qualifiée et statuts de preuve | Conservés sans publication de métriques sous gate. |
| Responsabilité senior et construction effective | Conservées dans le modèle Embed → Build → Run. |
| Identité noire, ivoire et vert signal | Conservée. |

## Partiellement compatible et recadré

| Wording ou structure précédente | Nouveau rôle |
| --- | --- |
| Systèmes opérationnels et de décision | Systèmes opérationnels intelligents. |
| Processus, donnée et IA | Context → Execution → Intelligence. |
| CRM, automatisation et agentique présentés séparément | Trois couches interdépendantes d’un même système. |
| Méthode de mission séquentielle | Delivery au contact de l’opération : Embed → Build → Run. |
| Équipe senior comme élément de crédibilité | Équipe comme asset de delivery, jamais comme offre. |
| Cas décrits par leur technologie | Récit Before → Context → Execution → Intelligence → Human Control → Outcome. |

## Contradictoire et retiré

- catégorie d’agence IA ou d’agence d’automatisation ;
- catalogue de services indépendants ;
- collectif d’experts, profils disponibles ou logique de staffing ;
- technologie, agent ou chatbot présenté comme produit vendu ;
- slogans concurrents et promesses génériques de productivité ;
- CTA centré sur l’achat d’une expertise ou la réservation d’un consultant.

## Nouvelle colonne vertébrale

La homepage suit désormais : problème → thèse → expertise → modèle → capabilities → delivery → différence → preuve → builders → CTA.

La hiérarchie de message est limitée à quatre niveaux :

1. catégorie : Intelligent Operations ;
2. promesse : From disconnected tools to intelligent operations ;
3. headline : Des outils fragmentés aux opérations intelligentes ;
4. thèse : AI is only as useful as the operation it can act on.

## Décision UX

Le scaffold reste explicite sans devenir un manifeste. Les paragraphes sont courts, les trois capabilities partagent un même contenant visuel et la preuve de l’accueil est abrégée. Le récit complet du système est réservé à la page Réalisations.
